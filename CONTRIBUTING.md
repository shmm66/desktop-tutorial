# Contributing to Trader Planner Pro

Trader Planner Pro is intended to be fully open source and forkable.

## Before contributing

1. Read `AGENTS.md`.
2. Read `ARCHITECTURE.md`.
3. Keep Forex and Crypto domains separated.
4. Do not put secrets or API keys in source control.
5. Add or update tests for behavior changes.
6. Use a feature branch and submit a Pull Request.
